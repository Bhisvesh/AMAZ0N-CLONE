# Amazon Clone - Frontend Replicas

A pixel-perfect, fully responsive **Amazon Homepage Clone** built from scratch using only **HTML5** and **CSS3**. This project was created to master modern CSS layouts, semantic HTML structure, and complex UI replication.

---

## 📌 Project Overview
This project replicates the signature layout, color palette, and visual structure of the original [Amazon Website](https://amazon.com). It focuses purely on front-end aesthetics, semantic markup, and responsive design components without relying on heavy JavaScript frameworks.

### Key Features Implemented:
* **Amazon Navigation Bar:** Replicates the multi-element navigation header featuring the Amazon logo, delivery location picker, localized search bar, language selector, accounts & lists dropdown, returns/orders, and shopping cart icon.
* **Sub-Navigation Links:** A secondary category bar providing quick access to daily deals, customer service, registries, and gift cards.
* **Hero Image Carousel Effect:** The iconic fading banner graphic serving as the background for the top row of product cards.
* **Dynamic Product Grid Layout:** Multi-column grid rows containing product cards with dynamic sizing, typography hierarchies, price listings, and "Shop Now" links.
* **Multi-tiered Footer:** Includes the "Back to Top" navigation link, categorized corporate information directories, and the copyright/legal localization footer.
* **Interactive Hover States:** Custom CSS transitions applied across navigation tags, buttons, and product tiles to mimic genuine user-experience indicators.

---

## 🛠️ Technologies Used
* **HTML5:** Utilized for structural, accessible, and semantic web scaffolding.
* **CSS3:** Leveraged modern properties like **Flexbox**, **CSS Grid**, absolute positioning, custom variables (for Amazon colors), and Media Queries.
* **Font Awesome:** Integrated for clean, scalable navigation and utility iconography.
